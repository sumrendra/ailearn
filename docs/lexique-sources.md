# TCF Canada lexique — sources

Curated vocabulary in `src/lib/content/tcf-exam-lexique.ts` is **not** copied from commercial prep lists or leaked exams.

**Core inventory (2026):** Target **1,000** exam-priority lemmas (high-yield TCF themes). Currently merged from base lists plus `tcf-exam-lexique-batch2.ts` through `batch5.ts`. IRCC does not publish a word count for NCLC 7 — that level is defined by TCF score thresholds (~B2). Full B2 proficiency is often estimated at **~3,000–4,000+ active words** in the wild; our deck is a focused subset, not your entire lexicon. Browse by topic on `/tcf/vocabulary`.

| Source | Use |
|--------|-----|
| [FEI TCF Canada](https://www.france-education-international.fr/en/test/tcf-canada) + *Manuel du candidat* (Version P, 2026) | Text types, progressive difficulty, format only |
| AI Learn mock papers 1–10 | In-context packs and future mining |
| [Lexique 4](http://www.lexique.org) (New et al., CC BY-SA 4.0) | Frequency prioritization for band A/B |
| [Termium Plus](https://www.btb.termiumplus.gc.ca) | Canadian institutional term consistency |
| Hand-authored examples | All example sentences in app content |

Official prep links for learners: [RFI Français facile](https://francaisfacile.rfi.fr/fr/), [TV5MONDE TCF](https://apprendre.tv5monde.com/fr/tcf).
